# 🚀 LINE 官方帳號預約管理系統 (LINE Reservation System)

這是一套專為 LINE 官方帳號量身打造的強大預約管理與全方位營運系統！全站採用獨特的 **新粗野主義 (Neo-brutalism)** 介面設計（高對比色彩、粗黑邊框、立體陰影），不僅帶來極具視覺衝擊力的美學體驗，更擁有強大的後台自動化排程與推播功能。系統完美結合 LINE LIFF，實現與使用者的無縫對接，並賦予管理者最彈性、最高效的營運控管能力！

---

## 🌟 系統詳細功能說明與範例情境

### 1. 📱 終端用戶預約介面 (LINE LIFF 客戶端)
客戶無需下載任何 App 或跳轉外部網站，直接在 LINE 官方帳號內點擊選單即可瞬間開啟預約系統。
*   **無縫整合登入**：自動透過 LINE 獲取用戶基本資料（大頭貼、顯示名稱），免去繁瑣的註冊與填表流程。
*   **直覺化日曆與空景篩選**：提供視覺化的日曆介面，自動隱藏店休或已額滿的日期。點選日期後，即時顯示該日剩餘可預約的「時段」與「項目」。
*   **智慧防呆與額度限制**：
    *   **次數上限防護**：若管理員設定了「每人預約次數上限」，當用戶超額時，按鈕會自動反灰並提示「已達預約上限」。
    *   **重複預約檢查**：自動阻擋使用者在同一天重複預約完全相同的項目。
> **💡 範例情境**：
> 家長想幫小孩預約「鋼琴體驗課」。他在官方帳號內點擊「我要預約」，畫面直接跳出下週可預約的日期。他點選下週二，系統顯示剩餘 14:00 與 15:00。他選了 14:00，並在備註欄填寫「小孩名字叫小明，無基礎」，按下送出即完成預約，全程不到 30 秒！

---

### 2. 📅 預約單管理與智慧排班 (Reservation Management)
後台將所有預約單清楚劃分為「待審核」與「已核准」，並以互動式日曆呈現。
*   **一鍵審核與自動推播**：管理員核准預約後，系統會自動發送設計精美的「預約成功」LINE Flex Message 訊息給用戶。
*   **預約通知追蹤清單**：
    *   提供獨立的分頁清單，顯示所有已核准使用者的預約資訊與 LINE 頭像。
    *   **自動推算通知排程**：系統會自動根據每筆預約的日期，精準推算出「前三日」、「前二日」、「前一日」與「當日」的發送日期。
    *   **狀態追蹤與手動重發**：若系統已成功發送通知，清單會顯示綠色打勾圖示。管理員可以隨時點擊「內容」預覽當時送出的訊息，或是點擊「重發」立刻再次推播該通知給用戶。
*   **智慧時段自動分配演算法 (Auto-Scheduler)**：針對累積的待審核訂單，只需點擊「自動排班」，系統會自動根據各時段的剩餘名額，為所有待審核單尋找最佳時間配置。並支援**滑鼠拖曳 (Drag & Drop)**，輕鬆手動微調預約衝突。
> **💡 範例情境**：
> 用戶預約了 8/15 的剪髮服務。管理員在「預約通知清單」中，看到系統預計在 8/13 發送「前二日提醒」。到了 8/13 晚上，系統自動發送完畢，清單上亮起綠色勾勾。如果客人打電話來說沒看清楚訊息，管理員只要在清單上按下「重發」，客人手機馬上就會再收到一次完美的排版通知！

---

### 3. 🎨 訊息設定與專業編輯器 (Message Settings)
提供業界最強大的客製化訊息編輯中心，所有推播訊息皆可自訂成您的品牌風格。
*   **全域預約提醒排程**：管理員可針對「前三日、前二日、前一日、當日」分別設定是否啟用通知，並**自訂每個通知的發送時間**（例如：前一日的 20:00 發送，當日的 09:00 發送）。
*   **專業級富文本編輯器 (Rich Text Editor)**：
    *   **完美對應 LINE 字體**：內建 10 種字級大小 (10px ~ 32px)，100% 完美轉換為 LINE Flex Message 的 `xxs` 到 `5xl`，並支援「同行混排大小字」的最佳化行高計算！
    *   **豐富調色盤與光譜選色**：內建整理好的 8 大色系調色盤（包含 LINE 官方經典綠），並提供原生「光譜選取器」，讓您選用高達 1,677 萬種無窮色彩！
    *   **完整版 Emoji 支援**：內建原生表情符號選單，讓訊息更生動。
*   **動態變數插入**：點擊按鈕即可在主標題或內文中插入 `{好友的顯示名稱}`、`{預約日期}`、`{預約時段}`、`{預約項目}`、`{用戶星座}` 等變數，為每一位顧客打造專屬客製化訊息！
> **💡 範例情境**：
> 管理員在「前一日通知」設定：
> 主標題：`{好友的顯示名稱} 明天見！` (設定為 28px 超大字體，使用 LINE 綠色)
> 內文：`哈囉！您預約的 {預約時段} {預約項目} 就在明天囉！請記得準時出席~ 🥳`
> 當排程時間一到，用戶就會在手機上看到專屬於他名字的精緻大字體卡片！

### 4. 📢 群發活動與分眾行銷 (Event Notifications)
強大的行銷與公告工具，讓官方帳號變成您的最強行銷武器！
*   **活動建立與排程**：自訂活動主題，使用上述的專業編輯器撰寫圖文並茂的行銷內容，並指定未來的發送日期與確切時間。
*   **精準分眾受眾篩選**：發送對象除了「全部人員」外，支援「用戶標籤篩選」。系統會即時計算並顯示目前符合該標籤條件的人數。
*   **活動狀態追蹤**：列表清楚標示活動是「等待發送中」還是「已發送完成」，並支援分頁顯示以管理大量歷史活動。
> **💡 範例情境**：
> 下週即將迎來中秋節，店長想要舉辦「熟客專屬優惠」。他在後台建立一檔新活動，受眾篩選選擇「VIP」標籤（系統顯示共 45 人符合），並設定在週五下午 18:00 發送。時間一到，這 45 位 VIP 就會收到精美的中秋特惠圖文訊息！

---

### 5. 👥 深度用戶管理 (User Management)
不僅是預約系統，更是您專屬的迷你 CRM (客戶關係管理) 系統。
*   **自動建檔與鎖定名稱**：所有使用過預約系統的用戶都會自動建檔。若用戶的 LINE 名稱太奇怪，管理員可手動修改為「真實姓名」，系統將永久鎖定顯示此名稱，方便辨識。
*   **進階個資與星座自動推算**：管理員可為用戶補充性別、生日。系統會**自動根據生日推算出專屬的「星座」**！
*   **多維度自訂標籤**：可隨意為用戶貼上如「學生」、「VIP」、「常客」、「黑名單」等標籤，作為日後分眾行銷的重要依據。
*   **單獨客製推播**：在用戶列表中，點擊發送訊息按鈕，即可針對「單一用戶」發送即時客製化訊息。
> **💡 範例情境**：
> 客服人員在後台看到一位新用戶預約，透過現場對談得知他是大學生且下個月生日。客服立刻在後台將他的名稱改為「王小明」，輸入生日（系統瞬間自動算出他是『獅子座 ♌』），並加上「學生」標籤。到了下個月初，店長就能利用行銷工具，對所有「獅子座」或「學生」標籤發送專屬的生日壽星折扣碼！

---

### 6. ⚙️ 彈性時段與預約項目設定 (Availability)
*   **預約項目字典**：可無限建立不同的預約項目（例如：剪髮、燙髮、美甲），並自訂各自的專屬色彩與單日預約次數上限。
*   **快速排班與批次複製**：提供直覺的點擊排班介面。排定某一天的營業時段（例如 09:00, 10:00）與名額後，點擊「一鍵複製」，即可套用到本月所有的「週一到週五」，三秒鐘完成整個月的排班！

## 🛠️ 技術架構與開發堆疊
- **前端框架**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **資料庫與後端 API**: [Firebase (Firestore, Storage, Auth)](https://firebase.google.com/) + Vercel Serverless Functions
- **樣式與 UI 設計**: [Tailwind CSS](https://tailwindcss.com/) (Neo-brutalism 新粗野主義 / 漫畫風) + [Lucide React](https://lucide.dev/) (Icons)
- **排程與自動化機制**: 透過 Vercel Cron Jobs 觸發 API (`api/cron-events.js`)，實現定期自動檢查並觸發 LINE 通知與活動推播。
- **編輯器與排版引擎**: 整合 `react-quill-new` 與 `emoji-picker-react`，搭配自研的 HTML to LINE Flex Message 轉換引擎 (`htmlToFlex.js`)。
- **時間與曆法**: [date-fns](https://date-fns.org/) + [lunar-javascript](https://github.com/6tail/lunar-javascript)

## 💻 本地開發與部署運行
1. **安裝依賴套件** (因部分套件相依性，建議使用 legacy-peer-deps)
   ```bash
   npm install --legacy-peer-deps
   ```

2. **設定環境變數**
   請參考 `.env.example`，建立 `.env` 檔案，並正確填入您的 Firebase 與 LINE Channel API 金鑰。

3. **啟動開發伺服器**
   ```bash
   npm run dev
   ```

4. **編譯打包 (供部署至正式機)**
   ```bash
   npm run build
   ```
