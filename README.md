# LINE 官方帳號預約管理系統 (LINE Reservation System)

這是一套專為 LINE 官方帳號量身打造的強大預約管理系統，全站採用獨特的 **新粗野主義 / 漫畫風 (Neo-brutalism)** 介面設計，色彩鮮豔、極具互動性。系統結合 LINE LIFF 實現與使用者的無縫對接，並賦予管理者全面、彈性且高度自動化的營運控管能力！

---

## 🚀 系統特色與詳細功能說明

### 1. 📱 前台客戶端預約介面 (Client Side Booking Interface)
客戶無需下載任何 App 或註冊帳號，直接在 LINE 官方帳號點擊「預約」選單，即可自動登入並開始預約流程。
*   **無縫整合登入**：透過 LINE LIFF 自動獲取用戶基本資料（大頭貼、名稱），免去繁瑣的註冊流程。
*   **視覺化日曆與時段篩選**：提供直覺的日曆介面，自動隱藏未開放或已額滿的日期；點選日期後，即時顯示剩餘可預約的時段與項目。
*   **智慧防呆與次數限制**：
    *   **次數限制防護**：若管理員設定了「每人預約次數上限」，超額時按鈕反灰並提示「已達預約上限」。
    *   **衝突檢查**：阻擋使用者在同一天重複預約相同項目。
*   **範例情境**：家長要幫小孩預約「鋼琴體驗課」，進入 LINE 後可直接點選下週二的 14:00 時段，並在備註欄填寫小孩姓名，按下送出即完成預約。

---

### 2. 💻 預約管理與自動提醒 (Reservation Management)
後台將預約單清楚劃分為「待審核」與「已核准」兩大區塊。
*   **一鍵審核機制**：管理員核准預約後，系統會自動透過 LINE 推播「預約成功」的專屬 Flex Message 訊息。
*   **已核准預約月曆檢視**：以月曆模式直覺呈現每天的預約狀況。
*   **✨ 預約通知清單 (全新功能)**：
    *   提供獨立的分頁清單，顯示所有已核准使用者的預約資訊（包含帶有使用者 LINE 頭像的清單顯示）。
    *   **智慧推算排程**：系統自動根據用戶的預約日期，推算並標示出「前三日」、「前二日」、「前一日」與「當日」的實際發送日期。
    *   **發送狀態追蹤與手動重發**：若系統已成功發送提醒，列表會顯示綠色打勾圖示。點擊「內容」按鈕可預覽當時發送的圖文畫面；點擊「重發」按鈕則能立刻手動將該通知再次推播給該用戶！
*   **範例情境**：用戶預約了 8/15 的服務。在「預約通知清單」中，管理員可以看到系統預計在 8/13 (前二日) 發送提醒。若 8/13 已發送成功，清單會打勾；管理員也可隨時按下「重發」再次提醒用戶。

---

### 3. ⏰ 訊息與全域提醒設定 (Message Settings)
*   **全域預約提醒設定 (全新排程系統)**：
    *   管理員可針對「前三日、前二日、前一日、當日」分別設定是否啟用通知。
    *   支援自訂每個提醒的「發送時間」（例如前二日的晚上 20:00 發送，當日的早上 09:00 發送）。
    *   每個提醒皆可上傳專屬的橫幅圖片、自訂主標題與內文。
*   **動態變數支援**：不論是標題或內文，皆支援使用 `{好友的顯示名稱}` 變數。
*   **粗野主義確認視窗**：儲存設定時，採用與系統風格一致的漫畫風彈跳確認視窗，提升視覺一致性。
*   **範例情境**：設定「前二日通知」於 20:00 發送，標題為「預約提醒」，內文寫：「{好友的顯示名稱}您好，後天就是您的專屬服務日囉！期待您的到來。」系統會在條件符合時，自動透過排程發送這段客製化訊息。

---

### 4. 📢 群發活動通知 (Event Notifications)
強大的行銷與公告工具，讓您能夠精準觸及目標受眾！
*   **活動建立與排程**：可設定活動主題、純文字或圖文內容，並指定活動訊息的預計發送日期與時間。
*   **精準受眾篩選**：發送對象除了「全部人員」外，可選擇「透過用戶標籤篩選」。系統會即時顯示目前符合該標籤條件的人數。
*   **活動列表管理**：以分頁方式呈現所有建立的活動，並清楚標示各活動的狀態。列表支援分頁顯示（可設定 5 的倍數等分頁大小），方便大量資料管理。
*   **範例情境**：店裡舉辦「VIP 會員中秋節專屬體驗」，管理員新增一檔活動，受眾選擇標籤為「VIP」的用戶。設定於中秋節前一週的 18:00 發送。時間一到，系統便會自動將精美的中秋節圖文訊息群發給所有 VIP 用戶。

---

### 5. ⚙️ 強大的排班與時段設定 (Availability)
*   **預約項目字典**：可建立多個不同的預約項目（例如：保養、維修），並自訂項目名稱、標籤顏色與預約次數上限。
*   **彈性日曆排班與快速複製**：選定特定日期建立各時段的名額後，支援將該日設定「一鍵複製」到本月其他的特定星期（如所有週一到週五），大幅減輕排班負擔！
*   **智慧時段自動分配**：內建溯源演算法，只需點擊「一鍵自動排班」，系統會自動為待審核的預約者尋找最佳配置。配合視覺化網格與滑鼠拖曳 (Drag & Drop) 功能，輕鬆解決預約衝突。

---

### 6. 👥 用戶管理 (User Management)
*   **自動建檔與自訂名稱**：自動記錄所有登入用戶。管理員可修改使用者的「顯示名稱」（如改為真實姓名），系統將鎖定該名稱。
*   **多維度標籤與過濾**：支援為用戶加上「年齡群組」、「性別」、「專屬自訂標籤」（如 VIP、黑名單）。
*   **範例情境**：小編在後台看到一位新註冊的用戶，透過對話得知他是大學生，便在用戶清單中為他加上「學生」標籤。未來若有專屬學生的優惠活動，就能直接透過「活動通知」精準發送。

## 🛠️ 技術架構
- **前端框架**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **資料庫與後端**: [Firebase (Firestore, Storage, Auth)](https://firebase.google.com/) + Vercel Serverless Functions
- **樣式與 UI**: [Tailwind CSS](https://tailwindcss.com/) (Neo-brutalism 漫畫風設計) + [Lucide React](https://lucide.dev/) (Icons)
- **排程自動化機制**: 結合後端 Cron Jobs API (`api/cron-events.js`)，實現定期自動檢查並觸發推播。
- **時間與農民曆**: [date-fns](https://date-fns.org/) + [lunar-javascript](https://github.com/6tail/lunar-javascript)

## 💻 本地開發與運行
1. **安裝依賴套件** (因部分套件相依性，建議使用 legacy-peer-deps)
   ```bash
   npm install --legacy-peer-deps
   ```

2. **設定環境變數**
   請參考 `.env.example`，建立 `.env` 檔案，並填入您的 Firebase 與 LINE API 金鑰。

3. **啟動開發伺服器**
   ```bash
   npm run dev
   ```

4. **編譯打包 (供部署)**
   ```bash
   npm run build
   ```
